How it works

One API call per agent turn. The engine handles everything else.

Step 1
Agent acts
Sends observation to Identity OS
→
Step 2
Engine evaluates
Stress, drift, energy, modes
→
Step 3
Contract returned
Allowed/forbidden actions
→
Step 4
Agent obeys
Forbidden options removed
from identity_os_sdk import IdentityOS, Mode

client = IdentityOS(api_key="idos_sk_xxx")
instance = client.instances.create(name="Aria")

# Every agent turn: send observation, get contract
result = client.engine.process(
    instance_id=instance.id,
    mode_target=Mode.EXPLORATION,
    signal_strength=0.7
)

# Contract decides what the agent can do
contract = result.contract
if "explore" in contract.allowed_actions:
    # Safe to proceed
    ...
